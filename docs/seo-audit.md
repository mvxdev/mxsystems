# SEO-аудит mxsystems.md — версия до правок (коммит 34112ca, 25.10.2026)

Проверены все публикуемые страницы: `/`, `/ro/`, `/en/`, `/privacy/`, `/ro/privacy/`, `/en/privacy/`,
`/ru/` (переадресация) и `404.html`. Первый прогон `python tools/seo_check.py .` дал **61 ошибку**.

## Что было хорошо (уже сделано раньше)
- `<html lang>` верный на всех страницах (ru / ro / en).
- canonical на всех индексируемых страницах — абсолютный https, со слэшем, без www.
- hreflang ru / ro / en + x-default на трёх главных, взаимные.
- robots.txt: открыт, закрыты concepts/, tools/, archive/, есть ссылка на sitemap; assets не закрыты.
- sitemap.xml: 6 страниц, абсолютные адреса, xhtml:link hreflang, lastmod.
- 404 — `noindex`. `/ru/` — `noindex` + canonical на `/`.
- Open Graph на главных: og:title / description / url / image (1200×630, отдельная картинка на каждый язык), og:locale + 2 alternate, og:site_name.
- У всех `<img>` есть alt и width/height; картинки ниже первого экрана — `loading="lazy"`.
  Первый экран — текст (LCP — заголовок H1), картинок в нём нет, поэтому lazy ничего не тормозит.
- Один H1 на каждой странице, H2–H5 без пропусков уровней.
- favicon (SVG), apple-touch-icon, theme-color. Шрифты: preconnect + `display=swap`.
- Внутренних битых ссылок нет, http:// и www. нет, следов ClinicAI на страницах нет.
